# 平台退款渠道速查（事实库）

最后人工核实：2026-10。平台政策会变；**本库没有的商家必须 web search 官网核实，禁止凭记忆猜邮箱或入口。**

## 不走邮件，别写信

| 平台 | 正确渠道 | 要点 |
|---|---|---|
| Apple App Store / iTunes | reportaproblem.apple.com | 登录 Apple ID → 选订单 → 申请退款。内购退款主要入口，给客服写邮件没用 |
| Google Play | play.google.com → 付款和订阅 → 订单记录 → 申请退款 | 购买后 48 小时内在线申请最容易通过；超过后需联系客服 |
| Steam | help.steampowered.com → 购买 | 自助退款：购买 14 天内且游戏时长 < 2 小时 |
| Epic Games | 官网自助退款 | 14 天内 + 游戏时长 < 2 小时，部分商品例外 |
| Xbox / Microsoft Store | account.microsoft.com → 订单历史 → 申请退款 | 14 天内且未大量使用 |
| PlayStation Store | 官网客服退款表单 | 14 天内且未开始下载/观看 |
| Nintendo eShop（美服） | 基本无退款政策 | 美服别浪费时间；欧服有 14 天冷却期例外 |

## 有支持渠道但非传统邮箱

| 平台 | 渠道 | 要点 |
|---|---|---|
| OpenAI / ChatGPT | help.openai.com 右下角聊天气泡提工单 | 无退款邮箱；订阅费一般不退，误购/重复扣款可试 |
| Netflix | 官网在线客服 / 请求回电 | 已使用的周期一般不退；因技术故障整月未用的可争 |
| Amazon 数字商品 | 订单页客服聊天 | 数字内容一旦使用基本不退；实体商品走订单页退货 |
| Notion | 应用内 Help 入口提交（须工作区所有者） | 年费扣款后 30 天内可退；发票号在 Settings → Billing → Invoices（2026-10 核实） |
| Gymshark | support.gymshark.com 在线聊天 | 无公开退款邮箱（2026-10 核实） |
| Twobird | support.twobird.com 工单 / support@twobird.com | （2026-10 核实） |

## 通常走邮件/工单的

| 类型 | 做法 |
|---|---|
| 一般 SaaS / 软件 | 官网 Help/Contact/Support 页的工单或 support 邮箱；不确定就 web search "产品名 + refund policy" |
| 域名/主机（Namecheap、GoDaddy 等） | 账户后台提工单；域名多数不退，主机常有约 30 天退款窗口 |
| PayPal 交易 | Resolution Center 开 dispute，约 180 天内 |

## 银行拒付（chargeback，最后手段）

- 信用卡：联系发卡行，通常交易后约 120 天内
- PayPal：Resolution Center，约 180 天内
- 支付宝/微信绑卡扣款的同样走发卡行
- 前置：发卡行处理争议时通常会问"是否先联系过商家"——所以不要跳过 final notice 直接拒付，与商家的书面往来记录本身就是拒付材料
- 小额争议（几十元级别）一般不值得走到拒付：时间成本常高于金额，还可能影响账号信用
- 风险：商家可能封禁账户；对同一商家多次拒付可能影响账户信用
